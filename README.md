# FlowState

## Описание проекта

**FlowState** — веб-приложение для студентов, предназначенное для планирования учебного процесса, управления задачами и контроля дедлайнов.

Приложение позволяет создавать учебные задачи, устанавливать сроки их выполнения, отслеживать учебную нагрузку и формировать рекомендуемый план занятий с учётом доступного времени по дням недели.

## Функциональные возможности

### Управление задачами

- Создание, редактирование и удаление учебных задач.
- Указание названия задачи и учебного предмета.
- Установка дедлайнов.
- Выбор приоритета: низкий, средний или высокий.
- Указание предполагаемого времени выполнения.
- Автоматическая оценка времени выполнения на основе названия задачи.
- Изменение статуса задачи: новая, в процессе, выполнена.
- Фильтрация и сортировка задач по статусу, приоритету и срокам выполнения.

### Календарь

- Просмотр задач в календарном формате.
- Отображение дедлайнов по дням.
- Переключение между месяцами.
- Просмотр задач на выбранную дату.
- Отображение запланированного и доступного времени.

### Dashboard

- Отображение общей статистики по задачам.
- Просмотр количества активных и выполненных задач.
- Отображение ближайших дедлайнов.
- Просмотр учебной нагрузки на ближайшие семь дней.
- Отображение рекомендуемого плана занятий.
- Быстрый переход к задачам на выбранный день.

### Планирование учебной нагрузки

- Настройка доступного времени для учёбы по дням недели.
- Распределение задач с учётом дедлайнов и приоритетов.
- Расчёт предполагаемой учебной нагрузки.
- Выявление просроченных задач и нехватки доступного времени.

### Пользовательский аккаунт

- Регистрация с использованием электронной почты и пароля.
- Авторизация пользователя.
- Выход из аккаунта.

## Архитектура проекта

Приложение построено на основе Next.js App Router.

- **Серверная часть** отвечает за получение данных, проверку авторизации и загрузку информации из Supabase.
- **Клиентская часть** обеспечивает взаимодействие пользователя с задачами, календарём и другими элементами интерфейса.
- **Server Actions** используются для изменения статусов задач и сохранения настроек учебного времени.
- **Бизнес-логика** вынесена в отдельные модули и включает планирование задач, расчёт учебной нагрузки, работу с календарём и оценку времени выполнения.

Для работы с базой данных и авторизацией используется Supabase.

## Установка и запуск

### 1. Настройка переменных окружения

В корневой папке проекта, рядом с `package.json`, необходимо создать файл `.env.local`.

Добавить в него параметры подключения к Supabase:

```env
NEXT_PUBLIC_SUPABASE_URL=https://vmrraxukhbhqbhffjazz.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_XaRkHh2_I27OSvWx1M5WoA_ikYlwPsu
```

Значения необходимо получить из настроек проекта Supabase.

### 2. Установка зависимостей

В терминале VS Code выполнить команду:

```bash
npm install
```

### 3. Запуск приложения

```bash
npm run dev
```

### 4. Открытие приложения

После запуска перейти в браузере по адресу:

```text
http://localhost:3000
```

Для остановки локального сервера используется сочетание клавиш `Ctrl + C` в терминале.

**Примечание:** для работы приложения необходимо настроить Supabase и создать необходимые таблицы базы данных. Миграция для `study_preferences` находится в папке `supabase/migrations/`.
